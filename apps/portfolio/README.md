# Portfolio app

Reserved for the [likwidmack/portfolio](https://github.com/likwidmack/portfolio) Nx monorepo — full-stack portfolio work (Nuxt 4 SSR, SQLite, Docker/Postgres, AWS SAM).

This directory is separate from `apps/profile/`, which publishes the professional profile at [tamaramack.github.io](https://tamaramack.github.io/).

| App | Path | Publishes |
| --- | --- | --- |
| Profile site | `apps/profile/` | `tamaramack.github.io` (`/` via `app/pages/index.vue`) |
| Portfolio repo | `apps/portfolio/` | [likwidmack/portfolio](https://github.com/likwidmack/portfolio) |

When the portfolio codebase is vendored or developed here, it lives under this path.
